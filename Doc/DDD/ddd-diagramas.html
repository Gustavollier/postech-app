1. Context Map — Mapa de Contextos Delimitados

📋 Atendimento

Recepção, identificação do cliente e abertura da OS

  • Cliente (Aggregate Root)
  • Veiculo (Aggregate Root)
  • OrdemServico — criação
  • Funcionario (Aggregate Root)
  • Seguranca (tabela de senha)

💰 Financeiro / Orçamento

Orçamentos automáticos e aprovação pelo cliente

  • Orcamento (tabela)
  • EStatusOrcamento (enum)
  • Cálculo: Peça + MãoDeObra + Serviço

🔧 Execução de Serviços

Ciclo de vida da OS, itens e histórico de status

  • OrdemServico (ciclo + status)
  • ItemOS (mão-de-obra / peça / serviço)
  • Status (histórico de transições)
  • Servico (catálogo)

📦 Estoque

Peças, insumos e ajustes de quantidade

  • Pecas (Aggregate Root)
  • Ajuste via PATCH /pecas/{id}/estoque
  • Filtro estoqueBaixo no GET

Relacionamentos entre Contextos:

Atendimento → Financeiro Customer/Supplier Itens adicionados à OS disparam cálculo do orçamento
Financeiro → Execução Customer/Supplier Aprovação do orçamento avança OS para EmExecucao
Execução → Estoque Customer/Supplier Finalização valida estoque disponível antes de completar
Atendimento → Execução Shared Kernel OrdemServico e ItemOS são compartilhados entre contextos

2. Agregados, Entidades e Value Objects

👤 ClienteAggregate Root
  • IdINT IDENTITY
  • NomeCompletoNVARCHAR(100)
  • CPFNVARCHAR(14) nullable
  • CNPJNVARCHAR(18) nullable
  • TelefoneNVARCHAR(20)
  • EmailNVARCHAR(100)
  • AtivoBIT
  • CreatedAtDATETIME
  • UpdatedAtDATETIME
VO: Placa (validação Mercosul) · CpfCnpj (dígitos verificadores) em Veiculo e Cliente
🚗 VeiculoAggregate Root
  • IdINT IDENTITY
  • ClienteIdINT (FK)
  • PlacaPlaca (VO) — Mercosul
  • MarcaNVARCHAR(50)
  • ModeloNVARCHAR(50)
  • AnoModeloINT
  • AnoFabricacaoINT
  • CorNVARCHAR(30)
  • KmEntradaINT
  • AtivoBIT
VO: Placa — regex Mercosul (AAA0A00). Formato antigo não suportado.
📋 OrdemServicoAggregate Root
  • IdINT IDENTITY
  • IdClienteINT (FK)
  • IdVeiculoINT (FK)
  • IdFuncionarioINT (FK) — responsável
  • StatusEStatusOrdemServico (INT)
  • CriadoEmDATETIME
  • AtualizadoEmDATETIME
Status: RECEBIDA(0) → EM_DIAGNOSTICO(1) → AGUARDANDO_APROVACAO(2) → EM_EXECUCAO(3) → FINALIZADA(4) → ENTREGUE(5) | saída alternativa: CANCELADA(6)
🔨 Servico (catálogo)Aggregate Root
  • IdINT IDENTITY
  • NomeNVARCHAR(100)
  • DescricaoNVARCHAR(500) nullable
  • PrecoBaseDECIMAL(10,2)
  • TempoEstimadoMinutosINT
  • AtivoBIT
  • CriadoEm / AtualizadoEmDATETIME
Exemplos: Alinhamento, Troca de Óleo, Balanceamento. Incluído em OS via ItemOS.TipoItem = Servico(2).
📦 PecasAggregate Root
  • IdINT IDENTITY
  • NomeNVARCHAR(100)
  • MarcaNVARCHAR(50)
  • CodigoNVARCHAR(50)
  • PrecoDECIMAL(10,2)
  • UnidadeMedidaINT (enum)
  • QuantidadeEstoqueINT
  • AtivoBIT
Sem entidade Reserva ou MovimentacaoEstoque. Ajuste via PATCH /pecas/{id}/estoque. Filtro via ?estoqueBaixo=true.
💰 OrcamentoTabela calculada
  • IdINT IDENTITY
  • IdOSINT (FK, UNIQUE)
  • ValorServicosDECIMAL(10,2)
  • ValorPecasDECIMAL(10,2)
  • ValorMaoDeObraDECIMAL(10,2)
  • ValorTotalDECIMAL(10,2)
  • StatusEStatusOrcamento: Pendente(0)/Aprovado(1)/Rejeitado(2)
Calculado via POST /orcamentos/os/{id}/calcular. Aprovação via POST /orcamentos/os/{id}/responder.
👨‍🔧 FuncionarioAggregate Root
  • IdINT IDENTITY
  • NomeNVARCHAR(100)
  • CPFNVARCHAR(14) — login
  • ContatoNVARCHAR(50)
  • CargoECargoFuncionario (INT)
  • ValorHoraDECIMAL(10,2) — Mão de Obra
ECargoFuncionario: Mecanico(0) · Recepcionista(1) · Gerente(2) · Estoquista(3) · Eletricista(4) · Lavador(5) · Supervisor(6). Senha armazenada na tabela Seguranca (BCrypt).
🔐 ItemOSEntity
  • IdINT IDENTITY
  • IdOSINT (FK)
  • TipoItemETipoItemOrdemServico: MaoDeObra(0)/Peca(1)/Servico(2)
  • QuantidadeItemINT
  • IdFuncionarioINT nullable — se MaoDeObra
  • IdPecaINT nullable — se Peca
  • IdServicoINT nullable — se Servico
Custo: MaoDeObra = Funcionario.ValorHora × Qtd · Peca = Pecas.Preco × Qtd · Servico = Servico.PrecoBase × Qtd

3. Endpoints RESTful (Visão de Domínio)

🔑 Todas as rotas requerem Authorization: Bearer <JWT>, exceto as marcadas como público. O cargo do funcionário autenticado determina o acesso: [Authorize(Roles="Gerente")] restringe ao cargo Gerente(2).

👤 Clientes — /api/v1/clientes

POST/api/v1/clientesCriar cliente (CPF ou CNPJ validado por dígitos)
GET/api/v1/clientesListar clientes (paginado: ?page=1&pageSize=10)
GET/api/v1/clientes/{id}Buscar por ID
GET/api/v1/clientes/cpf-cnpj/{cpfCnpj}Buscar por CPF ou CNPJ
PUT/api/v1/clientes/{id}Atualizar cliente Gerente
DELETE/api/v1/clientes/{id}Desativar cliente (soft delete) Gerente

🚗 Veículos — /api/v1/veiculos

POST/api/v1/veiculosCadastrar veículo
GET/api/v1/veiculos/{id}Buscar veículo por ID
PUT/api/v1/veiculos/{id}Atualizar veículo Gerente

📋 Ordens de Serviço — /api/v1/ordens-servico

POST/api/v1/ordens-servicoCriar OS (IdCliente, IdVeiculo, IdFuncionario)
GET/api/v1/ordens-servicoListar OS (filtros: ?status=&page=&pageSize=)
GET/api/v1/ordens-servico/{id}Detalhar OS
GET/api/v1/ordens-servico/{id}/statusConsultar status + histórico — público (sem JWT)
GET/api/v1/ordens-servico/valor/{id}Obter valor calculado da OS (decimal)
PATCH/api/v1/ordens-servico/{id}/statusAvançar status (IdFuncionario + Status no body)
PUT/api/v1/ordens-servico/{id}Atualizar dados da OS Gerente
DELETE/api/v1/ordens-servico/{id}Remover OS Gerente

📝 Itens da OS — /api/v1/itens-os

POST/api/v1/itens-osAdicionar item à OS (MaoDeObra, Peca ou Servico)
GET/api/v1/itens-os/{ordemServicoId}Listar itens de uma OS
GET/api/v1/itens-os/{ordemServicoId}/{id}Buscar item por ID
PUT/api/v1/itens-os/{ordemServicoId}/{id}Atualizar item Gerente
DELETE/api/v1/itens-os/{ordemServicoId}/{id}Remover item Gerente

🔨 Serviços (catálogo) — /api/v1/servicos

GET/api/v1/servicosListar serviços disponíveis
GET/api/v1/servicos/{id}Buscar serviço por ID
POST/api/v1/servicosCriar serviço Gerente
PUT/api/v1/servicos/{id}Atualizar serviço Gerente
DELETE/api/v1/servicos/{id}Desativar serviço Gerente

📦 Peças e Insumos — /api/v1/pecas

POST/api/v1/pecasCadastrar peça/insumo
GET/api/v1/pecasListar (?estoqueBaixo=true&limiteEstoqueBaixo=10)
PUT/api/v1/pecas/{id}Atualizar peça Gerente
PATCH/api/v1/pecas/{id}/estoqueAjustar quantidade em estoque (positivo=entrada, negativo=saída) Gerente
DELETE/api/v1/pecas/{id}Desativar peça Gerente

💰 Orçamentos — /api/v1/orcamentos

GET/api/v1/orcamentos/os/{idOS}Consultar orçamento — público (sem JWT)
POST/api/v1/orcamentos/os/{idOS}/calcularGerar ou recalcular orçamento
POST/api/v1/orcamentos/os/{idOS}/responderCliente aprova (1) ou rejeita (2) — público (sem JWT)

📊 Relatórios — /api/v1/relatorios

GET/api/v1/relatorios/tempo-medio-servicosTempo médio (minutos) entre EmExecucao e Finalizada

🔐 Autenticação — /api/v1/auth

🔓 Rotas públicas — não requerem JWT
POST/api/v1/auth/loginLogin por CPF + senha — retorna JWT e refreshToken
POST/api/v1/auth/refreshRenovar token JWT com refreshToken

👨‍🔧 Funcionários — /api/v1/funcionarios

🔑 Todas as rotas requerem JWT  |  Gerente = cargo Gerente(2)  |  QUALQUER = qualquer funcionário autenticado
POST/api/v1/funcionariosCadastrar funcionário com senha inicialGerente
GET/api/v1/funcionariosListar funcionáriosGerente
GET/api/v1/funcionarios/{id}Buscar funcionário por IDQUALQUER
PUT/api/v1/funcionarios/{id}Atualizar dados (nome, contato, cargo, valorHora)Gerente
DELETE/api/v1/funcionarios/{id}Desativar funcionárioGerente
