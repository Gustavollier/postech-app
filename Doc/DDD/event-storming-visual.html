📖 Linguagem Ubíqua (Ubiquitous Language)

Ordem de Serviço (OS)Documento central que registra todos os dados de um atendimento: cliente, veículo, serviços, peças e status corrente.
DiagnósticoFase em que o técnico avalia o veículo para identificar problemas e necessidades de reparo.
OrçamentoEstimativa financeira calculada automaticamente com base nos serviços e peças selecionados para a OS.
AprovaçãoAutorização formal do cliente para execução dos serviços listados no orçamento, via API/aplicativo.
InsumoMaterial consumível utilizado na execução do serviço (ex.: óleo de motor, fluido de freio, graxa).
PeçaComponente físico que é substituído ou instalado no veículo durante a execução de um serviço.
ReservaAlocação de uma peça/insumo do estoque a uma OS específica, tornando-a indisponível para outras OS.
EntregaAto final do atendimento: devolução do veículo ao cliente após conclusão dos serviços e pagamento.
Estoque MínimoQuantidade limite de uma peça/insumo abaixo da qual é gerado um alerta automático para reposição.
Tempo de ExecuçãoDuração registrada para cada serviço, utilizada no monitoramento de eficiência e geração de relatórios.
